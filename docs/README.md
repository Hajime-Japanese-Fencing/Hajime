# REGLES DE FONCTIONNEMENT DU KENDO

## Comment se gagne un combat

Un combat (**Shiai**) se déroule sur une aire carrée ou rectangulaire de 9 à 11 mètres de côté (**Shiaijo**), arbitré par 3 arbitres (**Shinpan**).

Un combat est gagné selon la règle du **San-bon Shobu** (match en 3 points) :

- Le vainqueur est le premier à marquer **2 ippons**
- Si le temps est écoulé avec **1 ippon chacun** ou **0-0** → **Hikiwake** (match nul)
- Si le temps est écoulé et qu'un seul combattant a **1 ippon** → ce combattant gagne
- En cas d'égalité : prolongation **Encho** (mort subite — le premier point marqué l'emporte)
- Si toujours égalité après prolongation : décision des arbitres **Hantei**, ou tirage au sort **Chusen**

---

## Les Ippons existants

Un **Ippon** est un point validé par les arbitres pour un combattant.
Les points existants sont les suivants :

- MEN (noté M)
- KOTE (noté K)
- DO (noté D)
- TSUKI (noté T)
- IPPON (noté I) donné à la suite de deux avertissements consécutifs donné par les arbitres à l'adversaire

## Avertissements

Un avertissement **Hansoku** (noté △) est un signal donné par les arbitres pour signaler une infraction au règlement.

## Formules de compétition (pour les règles officielles en France)

### 1. Poules préliminaires

- Groupes de **3/4 combattants ou équipes**
- Comptabilité sur : **victoires**, puis **ippons marqués** puis **ippons subits**
- En cas d'égalité en poule : combat supplémentaire en **Ippon Shobu** entre les concernés
- **Les 2 premiers de chaque poule** sont qualifiés pour le tableau final

### 2. Tableau final (élimination directe)

- Élimination directe après les poules
- Les ½ finalistes de la saison précédente et les clubs ayant le plus de représentants sont écartés dans le tirage au sort (dans la mesure du possible)
- Toujours **2 troisièmes ex æquo** (pas de match pour la 3e place en général)

---

## Combat en équipe vs Combat individuel

### Combat individuel

- Résultat selon **San-bon Shobu** (2 ippons pour gagner)
- Prolongation **Encho** si égalité
- Décision **Hantei** ou tirage au sort **Chusen** si toujours égalité

### Combat en équipe

- Équipes de **3, 5** (ou 7 avec deux remplaçants) combattants
- Chaque membre affronte son homologue dans l'équipe adverse en combat individuel
- **Positions dans une équipe de 5** : Sempo (1er), Jiho (2e), Chuken (3e = capitaine), Fukusho (4e), Taisho (5e = capitaine)
- L'équipe qui a le **plus de victoires** remporte le match
- En cas d'égalité du nombre de victoires → l'équipe avec le **plus d'ippons** gagne
- Si toujours égalité → les **capitaines (Taisho)** font un combat supplémnetaire en **Ippon Shobu** (un point gagnant) pour départager
